# Webcam Demo

Простое демо работы с веб-камерой в браузере на чистом HTML и JavaScript (`navigator.mediaDevices.getUserMedia`).

Возможности: включение и выключение камеры, выбор камеры, зеркальный режим, CSS-фильтры, снимки с сохранением в PNG.

Живая версия: https://aledigt.github.io/webcam-demo/

## Android APK

Download: https://github.com/aledigt/webcam-demo/releases/latest/download/webcam-demo.apk

Native Android app (Kotlin + CameraX, Material 3) in `android/`: preview, front/back switch, live colour filters, photo capture to Pictures/WebcamDemo, in-app gallery of recent shots.
Built and release-signed by GitHub Actions (`.github/workflows/android.yml`). Installing requires allowing installs from unknown sources.
If you installed v1 (debug-signed WebView build), uninstall it once before installing v2.

## iOS (unsigned IPA for sideloading)

Download: https://github.com/aledigt/webcam-demo/releases/latest/download/webcam-demo.ipa

Native SwiftUI + AVFoundation app in `ios/` (project generated by XcodeGen, built by `.github/workflows/ios.yml`). The IPA is **unsigned**; AltStore / Sideloadly sign it with your free Apple ID on install.

### Install on iPhone from Windows via AltStore
1. Install **iTunes** and **iCloud** downloaded directly from Apple's website (apple.com), **not** the Microsoft Store versions — AltServer does not work with those.
2. Download and install **AltServer** for Windows from https://altstore.io and run it (it appears in the system tray).
3. Connect the iPhone by USB, tap "Trust this computer", and in iTunes enable "Sync with this iPhone over Wi-Fi".
4. In the AltServer tray menu choose **Install AltStore → your iPhone**, sign in with your Apple ID.
5. On the iPhone: Settings → General → VPN & Device Management → trust your Apple ID. On iOS 16+ also enable Settings → Privacy & Security → **Developer Mode** and reboot.
6. Download `webcam-demo.ipa` on the iPhone (or AirDrop/share it), open AltStore → My Apps → **+**, pick the IPA.

(Sideloadly works too: drag the IPA into Sideloadly, enter your Apple ID, click Start.)

**Limits of a free Apple ID:** apps expire after **7 days** and must be refreshed in AltStore (with AltServer running on the same Wi-Fi, or via USB); at most **3 sideloaded apps** active at once (AltStore itself counts as one); max 10 app IDs per 7 days.
